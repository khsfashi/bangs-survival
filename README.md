# 앞머리 생존예보

습도, 이슬점, 강수확률, 바람을 이용해 앞으로 12시간의 `앞머리 생존점수`를 계산하는 모바일 우선 오픈소스 웹앱입니다.

## 제품 가설

기존 hair-weather 앱은 전체적인 frizz/curl 관리에 초점을 둡니다. 이 프로젝트는 한국 사용자의 좁은 질문인 **"오늘 앞머리를 세팅해도 유지될까?"** 에 집중합니다.

## 현재 기능

- 브라우저 현재 위치 또는 서울 데모 위치
- Open-Meteo 시간별 날씨 조회
- 습도 / 이슬점 / 강수확률 / 풍속 기반 deterministic risk score
- 앞으로 12시간 점수와 가장 유리한 시간 표시
- 점수에 따라 표정과 앞머리 상태가 달라지는 오리지널 SVG 캐릭터
- `유지됨 / 조금 무너짐 / 망함` 피드백을 하루 1개씩 localStorage에 저장하고 같은 날 재평가 시 수정
- 3일 이상 피드백부터 제한된 범위의 개인 calibration 적용
- 로그인, 서버 DB, LLM 없음

## 중요: 점수의 성격

현재 점수는 검증된 예측 모델이 아닙니다. 습도가 모발의 수분 흡수와 탄성에 영향을 준다는 선행 연구를 기반으로 변수는 선정했지만, 변수 가중치와 임계값은 MVP 제품 가설입니다. 실제 사용자 데이터를 이용한 검증 전에는 예측 정확도를 주장하지 않습니다.

## 개인정보

- 앱 자체 서버에 계정이나 위치 기록을 저장하지 않습니다.
- 현재 위치 좌표는 브라우저에서 날씨 조회에만 사용합니다.
- 민감도 설정과 결과 피드백은 브라우저 `localStorage`에만 저장합니다.
