# 앞머리 생존예보

한국 사용자가 외출 전에 **“오늘 앞머리를 세팅할 가치가 있는가?”**를 빠르게 판단하도록 돕는 모바일 우선 오픈소스 웹앱입니다.

## 현재 기능

- 브라우저 현재 위치를 예보 기준점으로 사용
- 카카오맵에서 마커를 끌거나 지도를 눌러 위치를 직접 보정
- 카카오 좌표→행정동 변환으로 현재 동네 표시
- WGS84 좌표를 기상청 동네예보 격자(nx, ny)로 결정론적으로 변환
- `KMA_API_KEY`가 있으면 기상청 동네예보를 우선 사용
- KMA 키 미설정 또는 일시 장애 시 Open-Meteo를 명시적인 fallback으로 사용
- 습도 / 이슬점 / 강수확률 / 풍속 기반 deterministic 생존점수
- 점수와 기상 요소에 따라 앞머리 행동 조언 제공
- 앞으로 12시간 점수와 가장 유리한 시간 표시
- 점수에 따라 표정과 앞머리 상태가 달라지는 SVG 캐릭터
- `유지됨 / 조금 무너짐 / 망함` 피드백을 하루 1개씩 localStorage에 저장
- 3일 이상 피드백부터 제한된 개인 calibration 적용
- 로그인과 서버 DB 없음

## 환경변수

Vercel 프로젝트에 아래 값을 설정합니다.

```text
KAKAO_JAVASCRIPT_KEY=<Kakao Maps Web JavaScript key>
KMA_API_KEY=<KMA APIHub auth key>
```

### Kakao Maps 키

`KAKAO_JAVASCRIPT_KEY`는 지도 Web SDK를 브라우저에서 로드하기 위한 **클라이언트 공개 키**입니다. 값 자체를 비밀키처럼 숨길 수 없으므로 Kakao Developers에서 서비스할 Vercel/커스텀 도메인을 허용 도메인으로 제한해야 합니다.

REST API 키, Admin 키 등 다른 인증정보를 이 환경변수에 넣으면 안 됩니다.

### KMA API 키

`KMA_API_KEY`는 `/api/weather` Vercel Function에서만 사용합니다. 브라우저 응답이나 저장소에는 노출하지 않습니다.

## 위치와 개인정보

- 브라우저 위치는 현재 예보를 계산하는 용도로만 사용합니다.
- 지도에서 보정한 좌표도 서버 DB에 저장하지 않습니다.
- 민감도 설정과 결과 피드백은 현재 브라우저의 `localStorage`에만 저장합니다.
- 화면에는 사용자가 선택한 행정동과 실제 기상청 격자 `(nx, ny)`를 함께 보여줍니다. 기상청 동네예보는 5km 격자이므로 가까운 두 위치가 같은 격자를 사용할 수 있습니다.

## 예보 데이터 정책

한국에서는 기상청 동네예보를 우선 데이터 공급원으로 사용합니다. 기상청 경로를 사용할 수 없는 경우에만 현재 Open-Meteo 경로를 fallback으로 유지합니다. 어떤 공급원을 사용했는지는 UI에 표시합니다.

현재 생존점수의 변수 선택에는 모발과 습도의 관계에 관한 선행 연구 근거가 있지만, 가중치와 임계값은 아직 제품 가설입니다. 실제 사용자 데이터로 검증하기 전에는 예측 정확도를 주장하지 않습니다.

## 테스트

외부 테스트 프레임워크 없이 Node 내장 테스트 러너를 사용합니다.

```bash
npm test
```

현재 테스트는 다음을 포함합니다.

- 기상 위험도 범위
- 서울·부산·제주·강남의 KMA 격자 변환 검증
- 이슬점 계산
- 기상청 발표시각 선택
- KMA 응답 정규화
- 날씨별 앞머리 행동 조언
- 점수별 판정과 캐릭터 상태
- 하루 1회 피드백 upsert
- 개인 보정 시작 조건과 상한
- 구형 localStorage 데이터 호환
